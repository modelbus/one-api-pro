# 用户管理

> 后台 → 用户管理。管理员账号登录后可见。

## 能做什么

| 操作 | 在哪里 | 作用 |
|---|---|---|
| **看列表** | 列表页 | 全部用户，可搜索、分页、按额度排序 |
| **新增用户** | 右上角「添加」 | 创建一个普通用户；不能创建比自己权限更高的角色 |
| **编辑** | 行内「编辑」 | 改名、改密码、改用户组、调整额度 |
| **启用 / 禁用** | 行内按钮 | 禁用后用户无法登录和调用 |
| **提升 / 降级** | 行内按钮 | 提升为管理员 / 降回普通用户；root 不可降级 |
| **充值额度** | 行内「充值」 | 给用户账号直接加额度（带备注） |
| **删除** | 行内「删除」 | 软删除；账号状态变为「已删除」 |

> 部分操作（禁用、删除、提升）仅 Root 可见；普通管理员只能编辑和充值。

## 列表能看什么

每行展示：

- 用户名（悬停提示邮箱）
- 显示名
- 所在用户组
- 当前活跃套餐（带到期日）
- 剩余额度 / 已用 / 请求次数
- 角色 chip（用户 / 管理员 / Root）
- 状态 chip（启用 / 禁用 / 已删除）
- 注册时间

顶部搜索框：输入关键字模糊搜 `username` / `display_name` / `email`。

## 给用户充值

最常用的功能。行内点「充值」按钮：

- 填充值额度（数字，内部单位）
- 填备注（会写入审计日志）
- 确认

充值立刻到账，并写一条充值日志。

## 禁用 vs 删除

| | 禁用 | 删除 |
|---|---|---|
| 用户能登录？ | 不能 | 不能 |
| 用户数据保留？ | 全部保留 | 全部保留（软删除） |
| 列表里看到？ | 是（标「禁用」） | 否（自动过滤） |
| 何时用 | 临时封禁（违规但还可能恢复） | 永久不再用 |

> 软删除 ≠ 物理删除。订单 / 调用日志会保留。Root 可以恢复。

## 角色与权限

| 角色 | 值 | 能做什么 |
|---|---|---|
| 普通用户 | `RoleCommonUser` (=1) | 用 API、看自己的数据 |
| 管理员 | `RoleAdminUser` (=10) | + 后台用户管理、订单、日志 |
| Root | `RoleRootUser` (=100) | + 系统设置、删除用户、配置支付 |

Root 账号不可被禁用 / 删除 / 降级。

## 批量操作

勾选多行后，底部出现「批量操作」下拉：

- 批量删除
- 批量禁用

结果以 toast 提示哪几个成功、哪几个失败（失败原因比如「无法操作 Root」）。

## 常见问题

- **调整额度后用户反映没到账**：调整会立即刷 Redis 缓存，下一个请求应看到新额度；如果仍异常，看后台「日志 → 用户操作」
- **新建用户后没收到验证邮件**：密码由管理员设，不需要邮件验证；除非管理员要求用户首次登录改密
- **不能删除某用户**：该用户可能是 Root，或在 Cluster 中是其他节点注册的；联系 Root 处理
