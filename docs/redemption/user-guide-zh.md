# 兑换码使用（用户）

> 拿到一张兑换码后怎么用。

## 怎么兑换

1. 登录后访问 `/redeem`
2. 把兑换码（24 位字符串）粘到输入框
3. 点「兑换」
4. 看到成功提示 → 额度已到账 / 订阅已激活

也可以直接在 [个人中心 → 兑换码](./user-guide) 里找到兑换入口。

## 兑换成功后

- **额度码**：账户 [余额](../schema/user) 直接 +N
- **套餐码**：一条新 [Subscription](../schema/subscription) 自动激活，到期时间 = 现在 + 该套餐的 duration_days

去 [个人仪表盘](../user/dashboard) 可以看到余额增加；去 `/subscription` 可以看到新订阅。

## 兑换失败

常见原因：

| 提示 | 含义 |
|---|---|
| 兑换码不存在 | 码输错了；重新核对一遍 |
| 已过期 | 过了 expiry_at；联系发放方 |
| 已用完 | 超过了 max_redemptions；联系发放方 |
| 已禁用 | 管理员主动禁用；联系发放方 |
| 已被当前账号兑换 | 单次码只能兑一次 |

## 常见问题

- **粘贴兑换码后还是失败**：检查前后空格、换行；不少码粘贴后会带隐藏字符
- **额度没到账**：刷新页面，或重新登录
- **重复输入同一张码**：除了「单次码」会拒绝外，不会出错；同一账号重复兑换会返回「已被当前账号兑换」
