# 兑换码管理

> 在 `redemptions` 表上批量生成兑换码，按关键字查询。后台 → 兑换码管理。

## 列表字段

每行显示一张兑换码（或一批的聚合行）：

- 码值（仅创建时显示一次；之后列表是脱敏的 `ABCD-****-1234`）
- 类型（额度 / 套餐）
- 额度值 / 套餐名
- 可兑次数 / 已兑次数
- 过期时间
- 状态（启用 / 禁用 / 已用完 / 已过期）

## 怎么生成一批

见 [兑换码管理（管理员）](./admin-guide)。

## 怎么查询

顶部搜索框 + 类型 / 状态筛选。

## 怎么禁用 / 删除

单条行内操作。建议优先「禁用」（可恢复），不要轻易「删除」（不可恢复，丢失审计）。

## 导出

列表右上角「导出」：CSV 或 TXT。建议生成后立即导出，因为码值不持久化在列表里。

## 常见问题

- **导出文件打不开**：CSV 用 UTF-8 编码，Excel 打开可能乱码；用「数据 → 自文本」导入
- **生成的码没人兑换**：检查码值是否正确发出去了（CSV 是否包含 `key` 列）
- **批量作废一批**：循环禁用单条；或联系管理员直接 SQL
