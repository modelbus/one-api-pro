# 订阅管理

> 后台 → 订阅管理。管理员可配。

## 列表

展示所有用户的活跃订阅。每行：

- 用户
- 套餐
- 状态（生效中 / 已过期 / 已撤销）
- 开始时间 / 到期时间
- 已用 / 总额度
- 操作按钮

可按用户、套餐、状态筛选。

## 操作

### 给用户手动开通订阅

1. 右上角「手动开通」→ 选用户、选套餐、选生效时间
2. 确认 → 用户立即获得订阅，不需要走支付

常用于：客服补偿、活动赠送、内部测试。

### 调整到期时间

1. 找到订阅行 → 「调整到期」
2. 改日期 → 确认

延长或缩短订阅有效期，不影响已用额度。

### 撤销订阅

1. 找到订阅行 → 「撤销」
2. 二次确认 → 订阅立即失效

常用于：违规处理、退款关联撤销。

## 状态说明

| 状态 | 含义 |
|---|---|
| 生效中 | 现在可用 |
| 已过期 | 超过 end_time，自动进入此状态（周期任务处理） |
| 已撤销 | 管理员手动撤销 |

## 批量操作

支持批量撤销（一般用于一次清退多个用户）。

## 常见问题

- **看不到某用户的订阅**：可能没订阅过；筛选条件里去掉「生效中」
- **撤销后用户余额被扣**：是的，撤销不影响 [充值额度](../schema/topup)。用户后续调用走按量计费
- **改了套餐，用户老订阅变了？** 不会。改的是套餐模板，老订阅沿用快照
