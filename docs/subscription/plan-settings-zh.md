# 套餐业务配置

> 后台 → 套餐业务配置。管理员可配。

## 当前可配项

### 升级模式（upgrade_mode）

用户已有订阅时再买新套餐，按哪种方式算钱？

- **差价模式**（默认）：按「差价」付，剩余额度折算到新订阅
- **叠加模式**：付全款开新订阅，旧订阅继续生效

详见 [套餐升降级](./upgrade-downgrade)。

## 怎么改

后台 → 套餐业务配置 → 选模式 → 保存。

修改后立即对所有后续升级生效；进行中的升级不受影响。

## 哪些场景需要改

| 场景 | 推荐模式 |
|---|---|
| 标准 SaaS | 差价（默认） |
| 高频升降级 / 临时试用 | 叠加 |
| 想让升级成为「续费」而不是「换套餐」 | 差价 |
| 想让升级能叠加用多个套餐 | 叠加 |

## 常见问题

- **改了模式，老订阅怎么办？** 不受影响。老订阅沿用订阅时的规则
- **差价模式能取消吗？** 不能。下单后只能撤销（管理员在后台操作）
