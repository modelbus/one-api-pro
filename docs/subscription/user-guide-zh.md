# 用户订阅使用指南

> 用户视角的订阅面板。看到自己的订阅、用了多少、还剩多少。

## 在哪里

登录后访问 `/subscription`，列表展示你**当前所有活跃订阅**。

每条订阅卡片显示：

- 套餐名称
- 到期时间 / 剩余天数
- 各窗口（5 小时 / 7 天 / 30 天）的进度条
- 该订阅覆盖的模型列表
- 「查看用量」按钮 → 进入详情

## 怎么看进度条

每个订阅卡片最多显示 3 个进度条：

- **5 小时窗口**（period）：近 5 小时已经用了多少
- **7 天窗口**：本周
- **30 天窗口**：本月

任意一条进度条接近 100% → 颜色变红。**任意一条满了**（100%）→ 套餐视为耗尽，下次请求走按量计费。

## 怎么续期 / 升级

1. 点订阅卡片「升级」或去 `/pricing` 选套餐
2. 系统按 [套餐升降级](./upgrade-downgrade) 规则出订单
3. 支付完成后立即生效

也可以在订阅卡片点「取消」提前结束订阅（注意：大多数套餐不允许中途退订）。

## 订阅结束会怎样

- 订阅到期 → 自动失效
- 失效后调用不会断，但走 [按量计费](./billing-rules)
- 想恢复折扣，重新订阅即可

## 常见问题

- **进度条看起来没用完，但调用被拒**：可能某个窗口 100% 了。点「查看用量」看每个模型的细节
- **订阅还有但有调用失败**：看下用户的余额（[个人仪表盘](../user/dashboard)「总 Quota」），可能余额也用完了
- **升级套餐后没变化**：升级是异步的；通常几秒内生效
