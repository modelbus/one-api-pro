### ✨ 新增功能

- **用户管理服务端分页**：`GET /api/user/` 新增 `page`（1 基页号）与 `pageSize`（兼容 `page_size`，上限 100）参数，响应在保留 `data` 数组的前提下新增 `total` / `page` / `page_size`。前端分页条改由真实总数驱动，展示「共 N 条 · 第 X / Y 页」，并支持切换每页条数。
- **可读的表单校验提示**：新增 `common.ValidationMessage`，把 validator 的字段 + 规则映射为中英文文案（如「密码长度不能少于 8 位」），多个字段错误以「；」拼接；无法识别的字段回落为「该字段」，不再输出 `Key: 'User.Password' ... failed on the 'min' tag` 这类英文原文。
- **Tab 标题可测化**：新增前端纯函数 `src/utils/title.js` 与 Node 单测，标题拼装规则（页面标题 + 站点名、i18n 未命中回落）可独立验证。

### 🐛 问题修复

- **浏览器标签页标题被后端覆盖**：此前 `/api/status` 返回的 `system_name`（默认可能是 `one-api`）会无条件改写 `document.title`，导致刷新后标题变成站点配置值。现在标题只由路由 `meta.title` + 固定站点名 `ONE-API-PRO` 生成，并为所有页面补齐 `meta.title`，切换语言时即时刷新。
- **访问令牌复制在 HTTP 环境下静默失败**：`navigator.clipboard` 在非安全上下文（http 访问）或被拒绝授权时不可用，且原实现只挂了 `then`，失败无任何反馈。现改为异步 + `try/catch`，自动降级到隐藏 textarea + `execCommand('copy')`，仍然失败时提示「复制失败，请手动选中复制」。
- **用户列表翻页错位**：旧的「是否已到末页」推算会在总数变化或快速翻页时渲染空页/多一页，并引用了未定义的 `pageTotal`。现在页数完全来自后端 `total`，并加入 `fetchSeq` 竞态保护与越界页回退。
- **用户列表 `total` 与过滤条件不一致**：新增 `model.CountAllUsers()`，与 `GetAllUsers()` 使用完全相同的过滤条件（排除已删除用户），保证列表为空时总数依然准确。

### 🔧 重构

- **个人设置页精简**：移除「个人信息」与「访问令牌」两个分区及其表单状态与保存逻辑，相关能力统一收敛到右上角用户菜单的弹窗，页面只保留推广链接、第三方绑定与危险操作区。
- **令牌弹窗交互**：「访问令牌」弹窗在输入框右侧内嵌复制图标（带 tooltip 与 `aria-label`），并在上方提示「令牌（仅显示一次，请复制保存）」。

### ⚠️ 升级注意事项

- `GET /api/user/` 的 `data` 仍为数组，新增字段为向后兼容的附加字段；只传旧参数 `p`（0 基页索引）的调用方行为不变。
- 个人设置页不再提供修改个人资料与生成访问令牌的入口，请使用右上角用户菜单。
- 无数据库结构变更，无需执行迁移脚本。
