# v0.0.1

::: v-pre


### ✨ New Features
- Introduced a brand-new admin web project `web/default-pro` powered by Arco Design.
- Completed the core admin console covering channels, users, billing, and logs.
- Added an automated release shell script and GitHub Actions workflow so future versions can publish binaries via tag push.

### 🔧 Refactor
- Removed legacy Docker support to focus on a clean binary distribution flow.

### 📚 Documentation
- Refreshed README with API notes and quickstart steps.
- Dropped Docker-related docs and unified the release notes.
