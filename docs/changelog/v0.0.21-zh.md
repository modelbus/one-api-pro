# v0.0.21 — 全量中英文国际化 + 配额缓存一致性修复 + tiktoken 离线内嵌

> 管理后台 / 落地页 / 登录注册 / 条款隐私全部支持中英文实时切换，Arco Design 组件同步本地化；修复 Redis 用户配额缓存与实际余额不一致的多条链路，并修复防火墙环境下 token 计数 panic。tiktoken BPE 编码文件内嵌进二进制，离线开箱即用。

> Full zh/en internationalization across the admin console, landing page, auth and legal pages, with Arco Design components localized too. Fixes multiple Redis user-quota cache staleness paths and a token-counting panic in firewalled environments. tiktoken BPE encodings are embedded into the binary for zero-config offline startup.

## 中文

### ✨ 新增功能

- **全量中英文国际化（i18n）**：
  - 管理后台全部页面（渠道 / 令牌 / 用户 / 套餐 / 订阅 / 订单 / 管理端订单 / 日志 / 兑换码 / 运营数据 / 系统 / 集群 / 运营 / 定价 / 充值 / 支付 / 个人设置）、控制台、落地页、登录 / 注册 / 重置密码 / OAuth、服务条款与隐私政策全部支持中英文。
  - 顶栏与落地页导航新增语言切换组件（`LangSwitcher`），选择持久化到 `localStorage.lang` 并同步 `<html lang>`。
  - 菜单、页面文案、表格列、弹窗、按钮、提示语、表单校验、`Message` 提示全部随语言实时切换。
- **Arco Design 组件多语言**：`App.vue` 通过 `a-config-provider` 注入 Arco 语言包（`zh-cn` / `en-us`），日期选择器、分页、空态、Popconfirm 等内置组件本地化。
- **语言包按页面模块拆分并自动深合并**：新增 `src/i18n/pages/*.js` 页面语言模块，`src/i18n/pages.js` 通过 `import.meta.glob` 自动加载并递归深合并，多个模块共用命名空间也不会相互覆盖。
- **令牌界面优化**：
  - 「剩余 / 已用」额度改为横排展示，`/` 分隔符同基线对齐。
  - 密钥列新增「查看完整密钥」弹窗，含一键复制与关闭。
  - 新增「可用模型」列，展示 `X个` / `不限制`，点击以网格 + 圆点弹窗展示模型列表；未限制模型时回退展示全部可用模型。
- **tiktoken BPE 离线内嵌**：通过 `//go:embed` 将 cl100k_base / o200k_base / p50k_base / r50k_base 4 个 BPE 文件（约 6.4 MB）编入二进制，无需任何环境变量即可精确计数 token，覆盖 gpt-3.5-turbo / gpt-4 / gpt-4o 等标准模型。

### 🐛 问题修复

- **修复 Redis 用户配额缓存与实际余额不一致**（多条链路）：
  - `IncreaseUserQuota` 直接写库后同步刷新 Redis，充值 / 管理员加额 / 邀请奖励后下一次请求立即可见。
  - 批处理模式（`BatchUpdateEnabled=true`）在 `batchUpdate` 落库后刷新对应用户缓存，保持 `users.quota` 与 `user_quota:<id>` 一致。
  - 管理员 `UpdateUser` 覆盖 `quota` 字段后同步刷新缓存，避免调额后用户被持续误报 403。
  - `preConsumeQuota` 的「余额充足免预扣」判定前移到 Redis 扣减之前，余额充足的请求不再让缓存逐次漂移；预扣失败时通过 `RedisIncrease` 回滚此前的 Redis 扣减。
  - 提高 `user_quota` 缓存低水位回源阈值（500 → 50_000），缩小高单价模型（如单次预扣约 80_000 quota）导致的「缓存漂移死区」，修复持续误报 `insufficient_user_quota` 403 的问题。
- **修复防火墙 / 离线环境下 token 计数 panic**：tiktoken 下载超时导致 fallback 不完整，`SyncOptions` 又把 `ApproximateTokenEnabled` 覆盖回 `false`，最终在 `nil` 编码器上调用 `Encode()` 触发 panic；内嵌 BPE 后整条链路消除。
- **修复令牌「永不过期」被误判为已过期**：过期时间 sentinel 从「仅 `-1` 表示永不过期」统一为「`<=0` 均视为永不过期」（`model/token.go` / `controller/token.go`），修复历史脏数据或旧前端把「永不过期」写成 `0` 后，启用令牌时被误报「令牌已过期」的问题；前端新增 `buildTokenExpiredTime` 纯函数，确保「永不过期」始终上报 `-1`。

### 🔧 重构

- **`httpBpeLoader` 改为三级查找**：内嵌（默认，开箱即用）→ `TIKTOKEN_CACHE_DIR`（高级用户覆盖，可跳过内嵌与 HTTP）→ HTTP 下载（兜底，应对未来 URL 变更）；同时取消此前隐式回退到系统临时目录 `data-gym-cache` 的行为（该目录用户感知不到，易被 `go clean -cache` 误清）。

### 📚 文档

- README 开发计划更新：将「多语言国际化（i18n）」移入**已完成**，新增「更多语言支持」规划项；同步简中 / 繁中 / 英 / 日 / 俄 / 德 / 韩 / 阿 共 8 个语言版本。

### 🧪 测试

- **`preConsumeQuota` 回归测试**：验证纯函数公式、余额不足 403 且不动 DB、免预扣路径不改动 `user.quota` 与 `token.remain_quota`、正常预扣路径、Plan 短路。
- **用户配额与缓存函数单测**：直接写库语义、负数拒绝、加减往返一致性、Redis 关闭时回滚函数为空操作。
- **tiktoken embedded loader 三级 fallback 单测**：4 个内嵌文件 SHA1 校验、未知 URL 优雅返回、解析 cl100k_base、端到端编码 gpt-3.5 / gpt-4 / gpt-4o、`TIKTOKEN_CACHE_DIR` 覆盖、HTTP 兜底。
- **令牌过期 sentinel 单测**：覆盖「永不过期」提交始终为 `-1`（永不返回 `0`）、`<=0` 不判过期、`>0` 正常判过期。

### ⚠️ 升级注意事项

- **零数据库迁移**：本次不涉及任何表结构变更。
- **需要重新构建前端**：`web/default-pro/` 的修改需 `npm run build` 后重新 `//go:embed` 进二进制。
- **后端二进制体积增加约 6.4 MB**：内嵌 4 个 tiktoken BPE 文件，用于换取离线可用与启动零阻塞；如需自定义编码，可设置 `TIKTOKEN_CACHE_DIR` 覆盖。
- **语言切换**：默认中文；登录后可在顶栏切换，落地页导航也可切换；选择写入 `localStorage.lang`。
- **构建与测试**：
  - `go build ./...` 通过。
  - `go test ./model/ ./controller/ ./middleware/` 全绿。
  - `cd web/default-pro && npm run build` 通过。

## English

### ✨ New Features

- **Full zh/en internationalization (i18n)**:
  - Every admin page (channels / tokens / users / plans / subscriptions / orders / admin orders / logs / redemptions / admin dashboard / system / cluster / operations / pricing / top-up / payment / personal settings), the console dashboard, landing page, login / register / password reset / OAuth, terms of service and privacy policy now support Chinese and English.
  - A language switcher (`LangSwitcher`) is added to the top bar and the landing navbar; the choice is persisted to `localStorage.lang` and synced to `<html lang>`.
  - Menus, page copy, table columns, modals, buttons, hints, form validation and `Message` toasts all switch in real time.
- **Arco Design component localization**: `App.vue` injects the Arco locale bundle (`zh-cn` / `en-us`) via `a-config-provider`, localizing date pickers, pagination, empty states, Popconfirm and other built-in components.
- **Per-page message modules with automatic deep merge**: new `src/i18n/pages/*.js` page modules are auto-loaded by `src/i18n/pages.js` through `import.meta.glob` and recursively deep-merged, so modules sharing a namespace never clobber each other.
- **Token page UI improvements**:
  - "Remaining / Used" quota is now laid out horizontally with a baseline-aligned `/` separator.
  - The key column gains a "view full key" modal with one-click copy and close.
  - A new "Available Models" column shows `X` / `Unrestricted`; clicking it opens a grid + dot modal listing models, falling back to all available models when the token is unrestricted.
- **tiktoken BPE embedded offline**: `//go:embed` bundles the cl100k_base / o200k_base / p50k_base / r50k_base BPE files (~6.4 MB) into the binary, so token counting is exact with zero configuration and no network, covering gpt-3.5-turbo / gpt-4 / gpt-4o and friends.

### 🐛 Bug Fixes

- **Fixed Redis user-quota cache drift versus the real balance** (multiple paths):
  - `IncreaseUserQuota` now refreshes Redis after a direct DB write, so top-ups / admin grants / invite rewards become visible on the very next request.
  - In batch mode (`BatchUpdateEnabled=true`), `batchUpdate` refreshes the affected users' cache after flushing, keeping `users.quota` and `user_quota:<id>` aligned.
  - Admin `UpdateUser` refreshes the cache after overwriting `quota`, preventing persistent false 403s after a quota edit.
  - The "trusted, skip pre-consume" guard in `preConsumeQuota` is moved before the Redis decrement, so funded requests no longer drift the cache on every call; on pre-consume failure, the prior Redis decrement is rolled back via `RedisIncrease`.
  - The `user_quota` cache low-water refresh threshold is raised (500 → 50_000), narrowing the drift dead zone caused by high-price models (~80_000 quota per pre-consume) and fixing persistent false `insufficient_user_quota` 403s.
- **Fixed token-counting panic in firewalled / offline environments**: the tiktoken download timeout left the fallback incomplete, `SyncOptions` flipped `ApproximateTokenEnabled` back to `false`, and `Encode()` was eventually called on a `nil` encoder; embedding the BPE files removes the whole chain.
- **Fixed "never expire" tokens being treated as expired**: the expiry sentinel is unified from "only `-1` means never expire" to "`<=0` means never expire" (`model/token.go` / `controller/token.go`), fixing the false "token expired" error when enabling tokens whose legacy/dirty value was `0`; the frontend adds a `buildTokenExpiredTime` helper so "never expire" is always submitted as `-1`.

### 🔧 Refactor

- **`httpBpeLoader` now resolves in three tiers**: embedded (default, works out of the box) → `TIKTOKEN_CACHE_DIR` (escape hatch for custom encodings, bypassing embedded and HTTP) → HTTP download (last resort for future URL changes). The previous implicit fallback to the system temp `data-gym-cache` directory is dropped (it was invisible and prone to `go clean -cache` collateral damage).

### 📚 Documentation

- README roadmap updated: "Internationalization (i18n)" moved to **Done** and a new "More languages" item added; synced across all 8 README languages (zh / zh-TW / en / ja / ru / de / ko / ar).

### 🧪 Tests

- **`preConsumeQuota` regression tests**: pure-function formula, insufficient-balance 403 without DB mutation, trusted path leaving both `user.quota` and `token.remain_quota` untouched, normal pre-consume path, and Plan short-circuit.
- **User-quota and cache helper unit tests**: direct-write semantics, negative-quota rejection, increase/decrease roundtrip consistency, and no-op rollback when Redis is disabled.
- **tiktoken embedded loader 3-tier fallback tests**: SHA1 validation of all 4 embedded files, graceful handling of unknown URLs, parsing cl100k_base, end-to-end encoding for gpt-3.5 / gpt-4 / gpt-4o, `TIKTOKEN_CACHE_DIR` override, and HTTP fallback.
- **Token expiry sentinel tests**: never-expire always submits `-1` (never `0`), `<=0` is not treated as expired, and `>0` expires correctly.

### ⚠️ Upgrade Notes

- **Zero database migration**: no schema changes.
- **Frontend rebuild required**: changes under `web/default-pro/` need `npm run build` so the assets are re-embedded into the Go binary.
- **Binary size grows by ~6.4 MB**: the 4 embedded tiktoken BPE files buy offline operation and non-blocking startup; set `TIKTOKEN_CACHE_DIR` to override with custom encodings.
- **Language switching**: defaults to Chinese; switch from the top bar after login or from the landing navbar. The choice is stored in `localStorage.lang`.
- **Build & test**:
  - `go build ./...` passes.
  - `go test ./model/ ./controller/ ./middleware/` is green.
  - `cd web/default-pro && npm run build` passes.
