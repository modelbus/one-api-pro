# v0.0.5 — 价格表布局重构

> 系统性修复「套餐价格表」的横向滚动与容器宽度问题；同时将 Go module 路径统一迁移到 `github.com/modelbus/one-api-pro`。

## 中文

### 🐛 问题修复
- 修复设置页 `setting-container` 没有 `width:100%`，导致价格表无法填满父容器的视觉问题。
- 修复 `setting-content` 在小窗口下不能收缩、价格表出现横向溢出但看不见滚动条的体验问题。
- 价格表现按 Arco Design `<a-table scroll>` 规范渲染：表头、列、操作列均能正常横向滚动，操作列固定在右侧。
- 兜底方案：将价格表改写为带 sticky 操作列的自定义 grid 表格，确保旧浏览器也能完整浏览。

### 🔧 重构
- 模块路径统一从 `github.com/Leon-PanPan/one-api-pro` 重命名为 `github.com/modelbus/one-api-pro`，所有 import 路径同步更新。

### 📚 文档
- 同步版本号文件中的版本号。

## English

### 🐛 Bug Fixes
- Fixed missing `width:100%` on `.setting-container` so pricing tables actually fill the parent.
- Resolved an issue where `.setting-content` wouldn't shrink on small windows, leaving pricing tables horizontally overflowing without a scrollbar.
- Rewrote pricing tables using Arco Design `<a-table scroll>` so headers, columns and the action column scroll horizontally as expected, with the action column pinned to the right.
- Added a fallback: a custom grid table with a sticky action column for legacy browsers.

### 🔧 Refactor
- Renamed the Go module path from `github.com/Leon-PanPan/one-api-pro` to `github.com/modelbus/one-api-pro`; all imports updated.

### 📚 Documentation
- Synced the version number in the version file.
