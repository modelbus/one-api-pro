# v0.0.4 — 渠道回退（fallback）

> 新增渠道级别的回退开关，让请求失败时按预设顺序自动尝试备用渠道。

## 中文

### ✨ 新增功能
- 新增 **渠道 fallback（回退）** 能力：每个渠道可标记为「回退渠道」，当主渠道请求失败时按配置顺序自动重试备用渠道，提升整体可用性。
- 在渠道编辑弹窗中提供「是否作为回退渠道」开关，操作更直观。

### 🐛 问题修复
- 修复渠道 fallback 开关无法持久化（保存后被重置）的问题。
- 解决编辑弹窗「提交」按钮在某些状态下被阻塞的问题。

### 📚 文档
- 更新 README，增补 fallback 渠道使用说明。

---

## English

### ✨ New Features
- Added **channel fallback** support: each channel can be flagged as a fallback so failed requests automatically retry on backup channels, improving overall availability.
- Surfaced the “use as fallback” toggle directly in the channel edit modal for clearer operation.

### 🐛 Bug Fixes
- Fixed the fallback toggle not persisting after save.
- Resolved an issue where the edit modal submit button could be blocked under certain states.

### 📚 Documentation
- Updated README with notes on configuring fallback channels.
