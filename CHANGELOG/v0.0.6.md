# v0.0.6 — 订单与支付（微信 / 支付宝）

> 引入「套餐订阅 / 订单」模块与独立支付设置页，支持微信支付与支付宝双通道。

## 中文

### ✨ 新增功能
- 新增 **套餐订阅 / 订单模块**：管理员维护套餐，用户在前台订阅并生成订单，订单生命周期完整可追溯。
- 接入 **微信支付** 与 **支付宝** 两种支付通道，下单 / 回调链路完整。
- 在设置侧边栏「运营」之后新增「支付」入口，跳转到独立的支付设置页。

### 🔧 重构
- 将原先混入 `OperationSetting.vue` 的支付配置独立成 `PaymentSetting.vue` 页面，职责更清晰。
- 移除 `OperationSetting.vue` 中的支付相关代码段。

### 🐛 问题修复
- 修正订单模块 + 外层路由的多处细节问题，确保下单、回调、状态流转符合预期。

### 📚 文档
- 中英文 README 增补「订单 / 支付」相关说明，并将订单模块特性移动到「已完成」清单。

## English

### ✨ New Features
- Added a **plan subscription / order module**: admins manage plans, users subscribe from the front-end and generate fully traceable records across the order lifecycle.
- Integrated **WeChat Pay** and **Alipay** end-to-end, including order creation and callback handling.
- Added a new **Payment** entry to the settings sidebar (after **Operation**) that links to a dedicated payment settings page.

### 🔧 Refactor
- Extracted payment configuration out of `OperationSetting.vue` into its own `PaymentSetting.vue` page for clearer separation of concerns.
- Removed the payment-related code blocks from `OperationSetting.vue`.

### 🐛 Bug Fixes
- Fixed several issues in the order module and outer routing to make order creation, callback handling and status transitions work as expected.

### 📚 Documentation
- Updated the Chinese & English README with an “Orders / Payments” section and moved order-module features into the Done list.

---

## ⚠️ 升级注意事项 / Upgrade Notes

- 首次升级后，请进入「系统设置 → 支付」填写 **微信支付** 与 **支付宝** 商户参数（AppID、商户号、回调地址等），否则下单支付将不可用。
- 已存在的运维配置（除支付外）保持不变，无需重新填写。
- 启动时会自动执行订单相关数据表迁移，建议提前备份数据库。
